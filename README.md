# GitHub 云盘

这是一个**纯静态**的云盘下载站：

- 自动读取同目录的 `云盘空间.zip`
- 支持文件夹层级浏览
- 图片 / 视频 / 音频 / PDF / Markdown / 代码 在线预览
- 一键下载单个文件

## 使用方法

1. 把要分享的文件打包为 `云盘空间.zip`
2. 与 `index.html` 放在同一目录
3. 部署到 GitHub Pages 即可

## 好处

1. 速度快不用担心限速等问题,这些都为github平台本身管理
2. 好上手只要复制到自己的仓库并Pages即可(可以修改`云盘空间.zip`)

## 为社么这样做

1. 你见过免费，开源，上手快，网页可操作，这些全都有的吗就算有上手也麻烦也小众(虽然此项目也小众)。
2. 有人说github本来就能当作一个网盘为社么还要这样?我只能说github本来就是一个用于分享源代码的所以下载等对新手等比较麻烦一堆洋文还要找到下载按钮，但是此项目点开链接即可。
